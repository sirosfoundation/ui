# Button

The button is available in two forms:

- **React**: the `<Button />` component from `@sirosfoundation/ui/react`.
- **Vanilla CSS**: the `s-button` class (plus modifiers) from `@sirosfoundation/ui/css`.

Both render identical markup and styling.
